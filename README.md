## What it does

- **A calm new-mail signal.** When mail arrives, a soft glow runs along the edge of the screen
  you're using and a small dot appears in the corner — **no sender, no subject, nothing to read**,
  so nothing pulls you out of your work or shows up on a shared screen. Click the dot to open your mail.
- Every mailbox in one place: All mail, folders, labels, categories, search.
- Write with templates, schedule for later, undo send.
- Automations, campaigns, contacts, domains, mailboxes and client access — the same account as
  the web and the phone app.
- Sign in with your password, or scan a QR code with the Mailaholic phone app.

## Installing

**Windows** — run `Mailaholic-Setup.exe`. If Windows SmartScreen says “Windows protected your PC”,
choose **More info → Run anyway**.

**macOS** — open the `.dmg` and drag Mailaholic into Applications. The first time, macOS may say
it can't verify the developer: open **System Settings → Privacy & Security**, scroll down and
click **Open Anyway** next to Mailaholic (or right-click the app → **Open**).

**Ubuntu / Debian** — `sudo apt install ./Mailaholic-linux-amd64.deb`, or double-click the file.

**AppImage** — `chmod +x Mailaholic-linux-x86_64.AppImage` and run it.
